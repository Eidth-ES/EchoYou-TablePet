# EchoYou · 回声·你 🐾

> 桌宠 + AI 情感陪伴 + 回声记录——让每一个被忽视的微小情绪，都能被听见、被回应、被记住。

基于 [EchoYou PRD v1.1](./PRD_EchoYou_v1.1.md) 实现的单文件 Web MVP，无需后端、无需构建，浏览器直接打开 `index.html` 即可使用。

## ✨ 功能

- **桌宠系统**：圆形电波球（电波随情绪变化波形）、拖拽移动、单击开对话、双击快速记录心情、呼吸/打滚/跳起/融化动画、4 种情绪状态（同频/守护/思考/期待）
- **对话系统**：三段式回应（共情 → 分析 → 建议）、4 种回应风格、情绪快选标签、上下文记忆
- **真实 LLM 接入（可选）**：在「我的 → AI 引擎」填入自己的 API Key（DeepSeek / 通义千问 / Kimi / OpenAI 或任意 OpenAI 兼容接口），即可启用真实大模型对话 + 深度情绪分析；不填则使用内置模拟引擎
- **自定义皮肤**：导入本地图片作为桌宠形象，自动圆形裁剪，原图不上传
- **回声日历**：对话自动归档，月视图圆点计数、记录详情（主题/情绪强度/关注点/行动建议/对话原文/个人备注）、周回声报告（情绪趋势 + 高频主题 + 洞察）
- **月度对话可视化（v1.1 新增）**：「回声」页默认 Tab，5 大图表讲一个月的故事：
  - 🔥 情绪热力日历（按强度上色，点击下钻）
  - 〰️ 情绪波动面积图（曲线 + 对话密度柱，自动标极值）
  - 🍩 话题占比环形图（点击扇区筛选主题）
  - 🎯 对话深度散点图（X=轮数、Y=强度、气泡=字数）
  - 💡 AI 生成的"这个月的你"洞察卡（最佳时刻/最常聊的事/需关注/走势）
- **右键 / 长按操作（v1.1 新增）**：回声记录卡片右键弹出菜单（查看详情/编辑备注/删除），含二次确认与危机记录强化提示
- **危机干预**：自伤/自杀倾向关键词检测 → 危机话术 + 心理援助热线（400-161-9995）+ 记录标记"需关注"
- **隐私**：全部数据仅存于本机浏览器 localStorage，可一键导出 JSON / 全部删除

## 🚀 使用

1. 打开 `index.html`（或访问 GitHub Pages 地址）
2. 首次引导：起昵称 → 选回应风格
3. 点桌宠聊天，关闭对话即自动归档到「回声」页
4. （可选）「我的 → AI 引擎」填入 API Key 启用真实 LLM
